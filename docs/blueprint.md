# **App Name**: GoWorld Tours

## Core Features:

- Tour Search and Display: Allow users to search for tours by city and view tour details with a gallery, itinerary, and inclusions.
- Hotel Booking: Enable users to search hotels by city and view hotel details, including star rating, price, and amenities. Link to availability.
- Vehicle Selection: Present different vehicle categories (Bike/Car/Tempo Traveller) with images, seating capacity, and inclusions. Provide a quote/availability flow.
- Itinerary Planner: A tool that lets users to create a day-by-day itinerary with time, title, and notes. The itinerary planner saves to localStorage or to the API
- User Authentication: Implement login/register functionality using email/password, with stubs for OTP and password reset flows.
- Vendor Onboarding: Allow restaurants, lodging, travel agents, and transport providers to register with KYC fields and an approval workflow.
- API Endpoints: Provide API endpoints for tours, hotels, vehicles, planner, vendors, auth, and payments.

## Style Guidelines:

- Primary color: A vibrant teal (#20A496) to evoke feelings of trust, reliability, and natural beauty, aligning with travel and exploration themes.
- Background color: A very light teal (#E0F4F1) for a calm and clean user interface.
- Accent color: A subdued blue (#457AB0), to provide a familiar, guiding experience in alignment with the GoWorld Tours branding (teal/blue).
- Body text and headlines: Use 'PT Sans' (sans-serif) for a modern yet warm aesthetic that is suitable for a travel platform.
- Use white cards with soft shadows and rounded-xl corners to present information in an organized, visually appealing manner.
- Incorporate subtle animations and transitions to enhance user engagement and provide a smooth browsing experience.
- Employ clear, intuitive icons to represent different tour features, hotel amenities, and vehicle types for easy navigation.
